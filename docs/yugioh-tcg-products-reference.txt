================================================================================
  YU-GI-OH! TCG PRODUCT REFERENCE — DM ERA THROUGH EARLY GX (2002–2008)
  Master Reference Document for Duell Monsters Classic
  Generated: 2026-03-17
================================================================================

This document covers ALL English TCG products from the original Duel Monsters
era through the end of the GX era (before 5D's/Synchro mechanics, roughly
2002–mid 2008). Products are organized by type and listed chronologically.

Key:
  [API] = Set exists in YGOPRODeck API (can be imported)
  [NO API] = Not found in API or has no importable cards
  Cards = Number of unique cards in the YGOPRODeck API database

Notes on card counts:
  - API counts include ALL printings/rarities, so they may be higher than
    the "unique cards" count you see on booster boxes.
  - Early sets (LOB, MRD, MRL, PSV, LON, LOD) have very high API card counts
    because they include 1st Edition, Unlimited, and reprint variants.
  - GX-era sets (60-card standard) have more consistent counts.

  13. WAVE PLANNING RECOMMENDATION

  Based on the chronological product releases, here is a recommended wave
  structure for the Duell Monsters Classic game progression:

  Wave 0: Starter Decks (SDY, SDK)
  Wave 1: LOB, MRD, SDJ
  Wave 2: MRL/SRL, PSV, SDP
  Wave 3: LON, LOD, PGD, SYE, SKE
  Wave 4: MFC, DCR
  Wave 5: IOC, AST
  Wave 6: SOD, RDS, FET, SD1, SD2
  Wave 7: TLM, CRV, EEN, SD3, SD4, SD5
  Wave 8: SOI, EOJ, POTD, SD6, SD7, SD8, YSD, DP1, DP2
  Wave 9: CDIP, STON, FOTB, SD09, SD10, DP03, DP04, DP05
  Wave 10: TAEV, GLAS, SDRL, DP06, DP07
  Wave 11: PTDN, LODT, SDDE (Final GX wave)

  Optional additions per wave:
    - Tournament Packs (TP1-TP8) can be sprinkled in as bonus content
    - Champion Packs (CP01-CP08) as tournament rewards
    - Duelist Packs as themed shop offerings
    - Collector's Tins as special shop products
    - Structure Decks as purchasable pre-built decks
    - Dark Beginning / Dark Revelation as "catch-up" packs
